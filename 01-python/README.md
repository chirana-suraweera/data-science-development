# 01 — Python Programming

A structured Python learning module for the Data Science development roadmap.

## Purpose
Build the Python programming foundation needed for data analysis, machine learning, data engineering and automation.

## Learning sequence
1. Python setup and first program
2. Variables, data types and operators
3. Strings and input/output
4. Conditional statements
5. Loops
6. Lists and tuples
7. Dictionaries and sets
8. Functions and scope
9. Comprehensions
10. Files and exceptions
11. Modules, packages and virtual environments
12. Object-oriented programming fundamentals
13. NumPy introduction (transition to data analysis)

## How to use this module
- Complete the Kaggle Learn Python course alongside these materials.
- Read the relevant note after each course lesson.
- Run and modify the example scripts; do not only read them.
- Attempt exercises before looking at solutions.
- Record your own explanations and mistakes.
- Complete at least one mini-project independently.

## Completion standard
You should be able to write and explain small Python programs using variables, conditions, loops, built-in data structures, functions, file handling and basic debugging. You should also be able to read unfamiliar beginner-level Python code and reason about its output.

## Important
This repository is a learning record. Update progress honestly. Do not mark a topic complete just because you watched a lesson.
