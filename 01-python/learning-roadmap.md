# Python Learning Roadmap

## Target
Develop practical Python fluency for data science work.

## Suggested sequence
| Stage | Topics | Evidence |
|---|---|---|
| 1 | Syntax, variables, types, operators | Small scripts |
| 2 | Strings, input/output, conditions | Input-validation program |
| 3 | Loops and iteration | Repetition and aggregation exercises |
| 4 | Lists, tuples, dictionaries, sets | Data transformation exercises |
| 5 | Functions, arguments, return values, scope | Reusable functions |
| 6 | Comprehensions, sorting, lambda basics | Compact data-processing tasks |
| 7 | Files, exceptions, modules | File-processing script |
| 8 | Classes and objects | Small class-based program |
| 9 | Debugging, testing basics, environments | Reliable, organised project |
| 10 | NumPy introduction | Numerical-array exercises |

## Weekly approach
1. Learn the concept using the linked course.
2. Reproduce examples without copying.
3. Complete exercises independently.
4. Explain the concept in your own words.
5. Commit your work to GitHub.
